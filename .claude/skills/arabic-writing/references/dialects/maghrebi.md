# Maghrebi Arabic (المغاربية / الدارجة)

**When to use:** Morocco (الدارجة), Algeria, Tunisia, Libya. Heavy Amazigh (Berber) and French
(and Italian/Spanish) influence makes it the least mutually intelligible with Mashreq dialects,
so **only target Maghrebi when the audience is specifically North African**. Use MSA for formal
text; for pan-Arab reach, MSA or white Arabic is safer than Darija.

**Orthographic conventions:** written in the standard alphabet (and very often in Latin
"Arabizi" online, e.g. numbers for letters: 3=ع، 7=ح، 9=ق). For published Arabic-script Darija,
use standard letters; the extended letters گ (g), ڤ (v), پ (p), چ (ch) appear for loanwords and
local sounds.

## Key lexicon vs MSA

| Meaning | MSA | Maghrebi (Moroccan/Algerian/Tunisian) |
|---|---|---|
| I want | أريد | بغيت (Mor.), نحب (Tun./Alg.) |
| now | الآن | دابا (Mor.), دروك / توا (Alg./Tun.) |
| thing | شيء | حاجة / شي |
| why | لماذا | علاش |
| where | أين | فين / وين |
| how | كيف | كيفاش |
| what | ماذا / ما | شنو / آش / واش |
| how much | كم | بشحال / قدّاش |
| good / nice | جيد | مزيان (Mor.), باهي (Tun.), مليح (Alg.) |
| very | جدًا | بزّاف |
| a little | قليلًا | شويّة |
| there is | هناك / يوجد | كاين |
| not (verb) | لا / ليس | ما…ش / ماشي |
| only | فقط | غير / برك |

## Grammar markers

- **Present tense** prefix **كـ / تـ** (Moroccan كـ): كنكتب ("I write / am writing"), كيمشي
  ("he goes"). Algerian/Tunisian often use the bare المضارع.
- **Future** prefix **غادي / ماش / باش / ح**: غادي نمشي (Mor.), باش نمشي / ماش (Tun./Alg.) ("I
  will go").
- **Negation:** circumfix **ما…ش** (ماكتبتش "I didn't write"); **ماشي** for nominal/adjectival
  negation (ماشي مزيان "not good").
- **Question word واش** often opens a yes/no question: واش جيتي؟ ("did you come?").
- **First-person singular** present takes the **نـ** prefix (نكتب = "I write," not "we") and the
  plural adds **ـو** (نكتبو = "we write") — a hallmark Maghrebi feature that differs from
  Mashreq conjugation.
- Heavy **vowel reduction / consonant clusters** (e.g. كتب → كْتب) are spoken features, not
  usually spelled.

## Naturalness notes & pitfalls

- The نكتب/نكتبو ("I/we write") prefix system is the loudest Maghrebi marker — getting it wrong
  immediately reveals non-native or Mashreq-default output.
- بزّاف ("a lot"), بغيت ("I want"), دابا ("now"), and علاش ("why") are core Moroccan tells;
  don't blend with عايز/بدّي/أبغى from other regions.
- French loanwords are pervasive in speech and casual writing (طوموبيل "car", طبلة, سيمانة
  "week"); use them only for authentic casual register, and stay consistent.
- Because Darija varies sharply across Morocco/Algeria/Tunisia/Libya, confirm the **country**
  before writing — a generic "Maghrebi" rarely reads as native to any one of them.
