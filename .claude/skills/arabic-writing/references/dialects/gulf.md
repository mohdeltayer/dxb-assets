# Gulf Arabic (الخليجية / اللهجة الخليجية)

**When to use:** Saudi Arabia, UAE, Kuwait, Qatar, Bahrain, Oman (Khaleeji). Important for
Gulf-market business, products, and social content. Note that "Gulf" covers several sub-variants
(Najdi, Hijazi, Emirati, Kuwaiti, Omani); the lexicon below is broadly shared, but pick the
country for high-stakes localization. Use MSA for formal/official text.

**Orthographic conventions:** standard alphabet. Distinctive phonology is usually **not** written
but worth knowing: ق often → /g/ (sometimes spelled ق or, informally, گ); ك can affricate to /tʃ/
(spelled ك or چ); ج often → /j/. Keep standard letters in writing unless deliberately phonetic.

## Key lexicon vs MSA

| Meaning | MSA | Gulf |
|---|---|---|
| I want | أريد | أبغي / أبي (Saudi), أبا / أبغى |
| now | الآن | الحين / الحّين |
| thing | شيء | شي |
| why | لماذا | ليش / وش السبب |
| where | أين | وين |
| how | كيف | كيف / جيف |
| what | ماذا / ما | وش / شنو (Kuwait) |
| how much / many | كم | كم / جم |
| good / nice | جيد | زين / حلو |
| very | جدًا | وايد / مرة |
| like this | هكذا | كذا / جذي |
| there is | هناك / يوجد | في / فيه |
| not (verb) | لا / ليس | ما / مو / مب |
| also | أيضًا | بعد |
| want to (let's) | … | يلا |

## Grammar markers

- **Present tense:** often the **bare** المضارع without a b- prefix (أروح "I go / I'm going"),
  though some areas use a b-future. Context carries aspect.
- **Future** particle **بـ** or **راح**: بروح / راح أروح ("I will go").
- **Negation:** **ما** before verbs (ما أدري "I don't know"); **مو / مب** for
  nominal/adjectival negation (مو زين، مب كذا).
- **Demonstratives:** هذا / هاظا (m.), هذي / هاي (f.), هذيل / هذولا (pl.).
- **Possession** particle **حق / مال**: السيارة حقّي / مالي ("my car").
- **وايد** ("a lot/very") and **زين** ("good/fine") are signature Gulf words.
- The feminine address suffix **-ich** (كيفِك → كيفِچ) is heard in Kuwait/eastern areas; written
  ك or چ.

## Naturalness notes & pitfalls

- أبغى/أبي ("I want") is the Gulf tell — don't substitute عايز (Egyptian) or بدّي (Levantine).
- الحين ("now"), وايد ("very"), and مو/مب (negation) together signal authentic Gulf; mixing in
  دلوقتي or هلّق breaks it.
- Saudi Najdi vs Hijazi vs Emirati differ in lexicon and pronunciation; for a specific market,
  confirm the country rather than writing generic "Gulf."
- For official Gulf communications, MSA remains standard; reserve dialect for marketing/social.
