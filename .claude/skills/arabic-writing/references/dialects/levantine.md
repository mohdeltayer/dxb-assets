# Levantine Arabic (الشامية / اللهجة الشامية)

**When to use:** Syria, Lebanon, Jordan, Palestine. Widely understood thanks to Levantine TV
drama and advertising; a common choice for warm, conversational marketing across the Mashreq.
Use MSA for formal text. There are sub-variants (Lebanese, Syrian, Jordanian, Palestinian);
pick the country when it matters, but the lexicon below is broadly shared.

**Orthographic conventions:** standard alphabet with phonetic informal spellings. ق is often a
glottal stop (especially urban Lebanese/Syrian) but written with the standard letter; some
writers use a leading ء or drop it informally.

## Key lexicon vs MSA

| Meaning | MSA | Levantine |
|---|---|---|
| I want | أريد | بدّي |
| now | الآن | هلّق / هلأ (Leb./Syr.), هسّا (Jor./Pal.) |
| thing | شيء | شي |
| why | لماذا | ليش |
| where | أين | وين |
| how | كيف | كيف |
| what | ماذا / ما | شو / إيش |
| how much / many | كم | قدّيش / كم |
| good / nice | جيد / جميل | منيح / حلو |
| very | جدًا | كتير |
| like this | هكذا | هيك |
| there is | هناك / يوجد | في |
| not (verb) | لا / ليس | ما / مش / مو |
| also | أيضًا | كمان |
| a little | قليلًا | شويّ |

## Grammar markers

- **Present tense** prefix **بـ**: بيكتب ("he writes"), بشتغل ("I work"). Bare المضارع after a
  modal: بدّي روح / بدّي أروح ("I want to go").
- **Future** prefix **رح** (or حـ): رح روح / رح يروح ("he will go").
- **Negation:** **ما** before verbs (ما بعرف "I don't know"); **مش / مو** for
  nominal/adjectival negation (مش منيح، مو هيك). The ـش suffix is less pervasive than in
  Egyptian.
- **Demonstratives:** هاد / هادا (m.), هاي / هيدي (f.), هدول (pl.) — often before the noun:
  هاد الكتاب.
- **Possession** particle **تبع**: السيارة تبعي ("my car").
- **Question words** can come first or last: شو اسمك؟ / وين رايح؟
- Characteristic **imāla** (raising of ā toward ē) in Lebanese, not normally written.

## Naturalness notes & pitfalls

- بدّي + bare verb (بدّي روح) is the natural "I want to," not the MSA أريد أن أذهب.
- Don't mix هلّق (Levantine) with دلوقتي (Egyptian) or الحين (Gulf) — that instantly reads as
  machine-blended Arabic.
- Lebanese marketing often code-switches with French/English ("bonjour", "merci"); use only if
  the brand voice calls for it, and keep it consistent.
