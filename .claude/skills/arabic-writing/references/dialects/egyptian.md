# Egyptian Arabic (المصرية / العامية المصرية)

**When to use:** the most widely understood dialect across the Arab world (film, TV, music), so
a strong default for pan-Arab informal content, comedy, dubbing, and consumer/social copy aimed
at Egypt. Not for formal documents — use MSA there.

**Orthographic conventions:** Egyptian is written with the standard Arabic alphabet plus some
informal spellings that reflect pronunciation. The final ya is often left undotted (إزاى) in
casual writing; when editing for publication, dot it (إزاي) unless it's a true alif maqsura.

## Key lexicon vs MSA

| Meaning | MSA | Egyptian |
|---|---|---|
| I want | أريد | عايز / عاوز (m.), عايزة (f.) |
| now | الآن | دلوقتي / دلوقت |
| thing | شيء | حاجة |
| why | لماذا | ليه |
| where | أين | فين |
| how | كيف | إزاي |
| what | ماذا / ما | إيه |
| how much / many | كم | كام |
| good / nice | جيد / جميل | كويّس / حلو |
| very | جدًا | قوي / أوي |
| like this | هكذا | كده |
| there is | هناك / يوجد | في |
| not (verb) | لا / ليس | مش / ما…ش |
| man / guy | رجل | راجل |
| money | مال / نقود | فلوس |

## Grammar markers

- **Present tense** prefixes **بـ**: بيكتب ("he writes / is writing"), بشتغل ("I work").
  Bare المضارع (يكتب) marks subjunctive/intent: عايز يكتب ("wants to write").
- **Future** prefix **حـ / هـ**: حيروح / هيروح ("he will go").
- **Negation:** circumfix **ما…ش** on verbs (مكتبش / ماكتبش "he didn't write"), and **مش** for
  nominal/future/adjectival negation (مش كويّس، مش هاروح).
- **Demonstratives** follow the noun: الراجل ده ("this man"), البنت دي, الناس دول.
- **Object/possessive suffixes:** كتابه، كتابها، بتاعي ("mine"). The genitive particle **بتاع /
  بتاعة / بتوع** marks possession: العربية بتاعتي ("my car").
- **Question words** usually go to the **end**: اسمك إيه؟ ("what's your name?"), رايح فين؟
  ("where are you going?").
- **ق** is typically pronounced as a glottal stop and **ج** as a hard /g/, but both are written
  with the standard letters.

## Naturalness notes & pitfalls

- Don't half-convert: text that keeps MSA syntax but swaps a few words reads as fake Egyptian.
  Convert the verb prefixes, negation, and word order together.
- Keep one dialect — don't mix Egyptian with Levantine/Gulf lexis (e.g. don't pair عايز with
  بدّي).
- For mixed audiences, "white Arabic" (lightly colloquial MSA) is often safer than heavy
  Egyptian.
