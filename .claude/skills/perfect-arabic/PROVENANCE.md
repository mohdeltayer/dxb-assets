# Provenance

Vendored unchanged from https://github.com/alialsaudi/perfect-arabic
(MIT, see LICENSE), folder `skills/perfect-arabic/` at commit
78fdade67ac2deb8d0d1433a6c12fa01d644f9b8 (11 Aug 2026), copied 1 Oct 2026.

The upstream README names the Claude Code entry point as
`claude-skill/SKILL.md`; no such path exists in the repo. The skill is
`skills/perfect-arabic/SKILL.md`, which is what this folder holds.

Not copied: the repo's `docs/` (install guides, nine test cases) and
`scripts/`. `agents/openai.yaml` is UI metadata for OpenAI surfaces and is
ignored by Claude Code.

The files here are a condensed community summary of النحو الوافي, not the
book. Known slips found on reading them in full are listed in
`.claude/skills/arabic-grammar-review/references/known-issues.md`; the
files themselves are left as upstream ships them so updates stay a clean
copy. Use them through `arabic-grammar-review`, which sets the house policy.
