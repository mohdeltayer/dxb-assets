# Arabic games & film editor — starter skill

Original instruction-only skill prepared for this request. It is not the third-party `ahmeddabak/claude-arabic-writing` skill, not an Anthropic product, and not a separate translation engine. It contains no executable scripts, external API calls or dependencies.

## Claude web / desktop

Enable Code execution and file creation in Settings > Capabilities. Then open Customize > Skills > + > Create skill > Upload a skill, upload the accompanying ZIP and enable it. Organization settings may restrict uploads.

## Claude Code

Put this complete folder in `~/.claude/skills/arabic-games-film-editor/` for personal use, or `.claude/skills/arabic-games-film-editor/` in one project.

## Test before relying on it

Compare outputs with and without the skill using the same source text and model. Check naturalness, preserved meaning, terminology and technical accuracy. This package's file structure has been checked, but it has not been installed or benchmarked in Claude.

For an initial test, ask: “Use the Arabic games and film editor skill to translate the following into natural MSA. Preserve all technical details and attribution. Return only the translation.”
