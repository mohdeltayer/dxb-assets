# Newsdesk files

One file per Production 2 run, `<YYYYMMDD-HHMM>.json` (Dubai), shape and checks in `newsroom/scout_file.py`
(adv-20261109-coordination-in-code, addendum 20:25 Dubai, 9 Nov 2026). The inbox mirror copies the last 48 hours into the
inbox `leads` collection for the Newsdesk tab. No whole Publer ids: `publer_ids_last6` only.
