# Editorial memory (adv-20261102-story-brief, part 3; Mohammad, 2 Nov 2026)

One entry per hold, correction or praise from Mohammad, newest first. Each entry: date (Dubai), the Reel, its story type,
what was wrong or right, and the rule in one line. A story brief pulls every entry of the same story type before the
angle is written. Add the entry the same day; when the rule belongs in `newsroom/reel-check.md`, add it there too, and a
wording correction goes into `newsroom/names-ar.md` as well. Read all three files before any build.

Story types: INTERVIEW, DELAY, OUT NOW, NUMBERS, REVIEWS, TRAILER OR FIRST LOOK, PEOPLE, EVENT, REPORT, LIST, SERIES, BREAKING (add as needed).
