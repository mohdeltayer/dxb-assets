## Limits
The grammar stage is a model step; the slip workflow has no model, so the slip records the review and the server refuses
a slip without it (or with texts changed after it). The Arabic-letters match reads consonants, so a different spelling
of the same sounds is caught, and an Arabic word that happens to share both consonant runs of a two-word name would be
too (none in the replay).
