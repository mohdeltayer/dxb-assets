# Release 2026-11-12 r2: people stories show the person; report is a label

Card adv-20261111-person-stories-gate, approved by Mohammad (the Harada Reel, 11 Nov 20:15 Dubai, went out with no face
and no name plate: Production 2 set kind "report" because the source was an outlet report, so the people rule and the
quote template were never reached). Live on merge.

## Changed paths

- templates/buildgate.py: `person_problems` (in problems() with the story file), `single_game`, PERSON_KINDS
  (quote, people, cast). The story file must carry "subject_person": null or {name, role, photo_source}. When it is set,
  or the kind is quote, people or cast: the job carries "subject_person" (the same), a "person" window opening at 0.0 s,
  and a kind other than report; with no licensed photo, "person_photo": "none" with "searched": [...] and the window
  shows their best-known work with the name plate. kind_news "report" is refused for a one-game story.
- templates/formats.py: `pick(..., single_game=True)` refuses report (REPORT_IS_A_LABEL); new kind `people`
  (trailer, quote).
- templates/qc.py: `person_shown` true, false or "n/a" in qc.json; false is a finding (verdict fail).
- templates/t0make.py: stops when the story file has no subject_person; copies it into the job and scaffolds the person
  entry opening at 0.0 s for people stories; passes single_game to formats.pick.
- newsroom/story-template.json: "subject_person": null.
- templates/test_persongate.py (9 tests); test_buildgate and test_presubmit fixtures carry the key; CLAUDE.md, STYLE.md,
  ops/production-setup.md line 12.

## Tests

All suites green. On the real Harada story (newsroom/stories/2026-11-11-harada-xbox-series-s-comment.json, kind report,
game Tekken) the gate now refuses the job twice: the story has no subject_person, and report is a label. With
subject_person filled in it refuses the same job three times: report is a label, the job does not copy subject_person,
and it has no person window on frame 0.

## Impact

None of the 880 story files on disk carries the key yet, so every story built from now on needs the line added (null
for most). The gate names it in one line; t0make stops on it first.
